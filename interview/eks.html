EKS: 100 interview questions

Thirty-four beginner questions, thirty-three intermediate, and thirty-three advanced. Each one has a direct answer.

Beginner

1. What is EKS?

Elastic Kubernetes Service is AWS's managed Kubernetes. AWS runs the control plane across availability zones. You run worker nodes or Fargate profiles.

2. What does AWS manage?

The API server, etcd, and the other control-plane processes. You own the VPC, node groups or Fargate, IAM, add-ons you install, and the workloads.

3. What is a managed node group?

An EC2 Auto Scaling group that EKS updates for you: AMI, kubelet version, and a rolling replacement of instances.

4. What is a self-managed node group?

An Auto Scaling group you build yourself, usually from a launch template. You own AMI updates and the kubelet version.

5. What is Fargate on EKS?

Pods run on AWS-managed compute with no EC2 nodes to patch. You define a profile by namespace and labels. DaemonSets and privileged pods are limited.

6. How does kubectl reach the cluster?

aws eks update-kubeconfig writes a context that runs the AWS CLI to get a token. The caller needs permission to call eks:DescribeCluster and the access entry or aws-auth mapping.

7. What is the cluster security group?

A security group EKS attaches so the control plane and nodes can talk. Extra rules belong in additional groups, not by editing this one blindly.

8. What is the shared responsibility on EKS?

AWS secures the control plane. You secure IAM, network rules, node AMIs, Kubernetes RBAC, and the images you run.

9. What is an AMI for a node group?

The machine image. Managed node groups use an EKS-optimized AMI that matches the Kubernetes minor. A mismatch causes nodes to fail to join.

10. Why must the node architecture match the image?

An arm64 image will not run on an x86 instance. The error looks like an exec format failure. Pick the AMI and the instance family together.

11. What is the VPC CNI?

The plugin that assigns pod IPs from the VPC subnets. Pods can be reached by other VPC resources. The subnet must have enough free addresses.

12. What is prefix delegation?

The CNI gives a node a prefix of addresses instead of one secondary IP per pod. It raises pod density and consumes subnet space in larger chunks.

13. What is IRSA?

IAM Roles for Service Accounts. A pod's service account is annotated with a role. The pod exchanges a projected token for AWS credentials through the cluster OIDC provider.

14. What is EKS Pod Identity?

A newer way to map a service account to an IAM role without a per-cluster OIDC provider you manage. An agent on the node performs the exchange.

15. When do you still use IRSA?

Clusters that already have it, or tooling that expects the OIDC provider. Do not attach both mechanisms to the same service account.

16. What is an OIDC provider for a cluster?

An IAM identity provider that trusts tokens the cluster issues. IRSA needs one provider per cluster. Pod Identity does not.

17. What is an access entry?

The current way to grant an IAM principal access to the Kubernetes API. It replaces hand-editing the aws-auth ConfigMap for new clusters.

18. What is the aws-auth ConfigMap?

The older mapping from IAM roles to Kubernetes groups. A bad edit can lock you out. Prefer access entries, and keep a break-glass role.

19. What is the cluster endpoint?

The API server address. It can be public, private, or both. Private means kubectl only works from inside the VPC or a connected network.

20. What is a public access CIDR?

The list of addresses allowed to use the public endpoint. Leave it open only for a lab. Pipelines and offices should be listed.

21. Can you skip Kubernetes minors on EKS?

No. Upgrade the control plane one minor at a time. UpdateClusterVersion rejects a jump.

22. What is version skew on EKS?

The control plane moves first. Node groups stay on an older minor until you update them, within the skew AWS currently allows. Confirm the number in the EKS docs before you plan the window.

23. How do you upgrade a managed node group?

update-nodegroup-version rolls the instances. It respects PodDisruptionBudgets. A budget that allows zero evictions stops the roll.

24. What is a launch template on a node group?

The EC2 settings: AMI, disk, user data, and security groups. Some updates force a new template version and a node replacement.

25. What is max unavailable during a node update?

How many nodes may be down at once. A low number is safer and slower. Quota must allow surge if you also set a surge.

26. What is the EKS add-on?

A managed install of vpc-cni, CoreDNS, kube-proxy, or the EBS CSI driver. EKS can update the add-on version with the cluster.

27. What is kube-proxy?

The component that implements Service ClusterIPs using iptables or IPVS. It is an add-on. Breaking it makes Service names fail.

28. What is CoreDNS on EKS?

Cluster DNS, also an add-on. A too-small replica count or a broken network policy makes every Service lookup fail.

29. What is the EBS CSI driver?

The driver that creates EBS volumes from PersistentVolumeClaims. The controller needs an IAM role. Without it, claims stay Pending.

30. What is the EFS CSI driver?

The driver for shared file systems. Use it when many pods must mount the same data. EBS is one node at a time.

31. What is a StorageClass?

The default class names the CSI driver and parameters such as volume type. Set a default or every claim must name a class.

32. What is an ALB Ingress?

The AWS Load Balancer Controller creates an Application Load Balancer from an Ingress. It needs a subnet tag and an IAM policy.

33. What is the subnet tag for load balancers?

kubernetes.io/role/elb on public subnets and kubernetes.io/role/internal-elb on private ones. Missing tags make the controller skip the subnet.

34. What is a Service of type LoadBalancer?

It creates a Network Load Balancer or a Classic one, depending on annotations. Prefer the load balancer controller for HTTP.

Intermediate

35. What is a security group for pods?

A VPC security group attached to pod ENIs. You can write rules against a pod the same way you write them against an instance. It needs the right CNI settings.

36. What is a node IAM role?

The instance role for the worker. It needs permissions to join the cluster, pull from ECR, and describe the VPC. Application permissions belong on IRSA, not on this role.

37. Why is a broad node role dangerous?

Every pod on the node can reach the instance metadata and use that role unless you block it. Pod Identity and IRSA exist so pods do not need the node role.

38. What is IMDSv2?

The session-based metadata service. Require tokens and set a hop limit so pods cannot easily steal the node role.

39. What is the hop limit for IMDS?

A hop limit of 1 stops containers from reaching IMDS. A hop limit of 2 allows them. Prefer 1 unless a pod truly needs the node role.

40. What is control-plane logging?

API, audit, authenticator, controller manager, and scheduler logs sent to CloudWatch. Audit is the one you want during an access incident.

41. What is envelope encryption for secrets?

Kubernetes secrets encrypted with a key from KMS before they sit in etcd. Turn it on for any cluster that holds real credentials.

42. What is a secret in etcd by default?

Base64, not encryption. Anyone who can read the secret object, or etcd, can read the value. Encrypt secrets and restrict RBAC.

43. What is a PodDisruptionBudget on EKS?

The same Kubernetes object. A node-group roll will not evict a pod when the budget allows zero disruptions. Fix the budget or the replica count.

44. What is a single-replica Deployment risk?

The roll drains its only pod and the Service has no endpoints until the new pod is Ready. Run two replicas or accept the blip.

45. What is Karpenter?

A node autoscaler that provisions instances from a NodePool spec. It can replace the cluster autoscaler. It needs its own IAM and interruption handling.

46. How is Karpenter different from the cluster autoscaler?

The cluster autoscaler scales groups you already defined. Karpenter picks instance types that fit pending pods, within your constraints.

47. What is a NodePool?

Karpenter's rule for capacity: instance families, zones, limits, and taints. A NodeClass holds the AMI and subnet details.

48. What is consolidation?

Karpenter deletes underused nodes and replaces them with a tighter fit. It can disrupt pods. Protect stateful sets with budgets and do-not-disrupt annotations.

49. What is an EKS managed add-on conflict?

You installed the same component with Helm and as an add-on. They fight. Pick one owner.

50. What is a platform version?

EKS's patch of a Kubernetes minor, such as eks.5. AWS applies platform patches. You still choose when to move the minor.

51. What is extended support?

A paid window after standard support ends. The cluster keeps running, at a higher control-plane price. Plan the upgrade instead of living there.

52. What is the control-plane price?

An hourly charge per cluster, plus the EC2 or Fargate you run. A forgotten lab cluster still bills the control plane.

53. What is a Fargate profile selector?

Namespace and labels that send matching pods to Fargate. Pods that do not match stay on EC2, or stay Pending if no nodes exist.

54. What cannot run well on Fargate?

DaemonSets, privileged pods, and pods that need host ports or specific instance storage. Plan those for EC2.

55. What is a core add-on on Fargate?

CoreDNS must have a Fargate profile or EC2 nodes, or DNS never starts and every pod looks broken.

56. What is aws-node?

The DaemonSet for the VPC CNI. If it crashes, new pods get no IP. Check it first when pods stay in ContainerCreating.

57. What is a custom networking mode?

Pods get IPs from a different subnet than the nodes. Use it when the node subnet is too small. It is easy to mis-configure.

58. What is an IPv6 EKS cluster?

Pods and Services use IPv6. The choice is at creation. Your CNI, load balancers, and security groups must all be IPv6-aware.

59. What is a cluster role versus a node role?

The cluster role is what the control plane assumes. The node role is what workers assume. Mixing their policies creates gaps or a role that is far too strong.

60. What is an access policy?

The Kubernetes permissions attached to an access entry, such as cluster admin or a namespace edit. It is the AWS-side form of RBAC for that principal.

61. How do you lock yourself out?

Delete the only admin access entry or break aws-auth with no other path. Keep a second admin role and test it before you remove the first.

62. What is a private-only cluster's CI problem?

The runner must sit on a network that can reach the private endpoint. A public hosted runner cannot. Use a self-hosted runner in the VPC.

63. What is an ECR pull on a node?

The node role, or the pod role, needs ecr:GetAuthorizationToken and the layer actions. A missing action looks like an image pull failure, not an IAM page.

64. What is imagePullBackOff?

The kubelet cannot fetch the image. Causes are a wrong name, a missing tag, a private repo, or an IAM denial. Describe the pod and read the events.

65. What is a multi-architecture image?

One tag with an index pointing at amd64 and arm64 manifests. The node pulls the one that matches its CPU. A single-arch tag fails on the other CPU.

66. What is a Bottlerocket node?

An AWS OS built to run containers, with a small attack surface. Managed node groups can use it. Operating it is different from Amazon Linux.

67. What is user data on an EKS node?

The bootstrap script that points kubelet at the cluster. A custom AMI that skips the EKS bootstrap never joins.

Advanced

68. What is default-deny?

A policy that drops all ingress or egress, then allow rules open what you need. Apply it per namespace after you know the real flows, or you will page yourself.

69. What is a security group rule versus a network policy?

Security groups act on ENIs in the VPC. Network policy acts on pod identity inside Kubernetes. You often want both.

70. What is the AWS Load Balancer Controller IAM?

A policy plus a service-account role. An under-privileged controller creates the Ingress and never creates the load balancer. The events say AccessDenied.

71. What is target group binding?

A custom resource that attaches pods to an existing load balancer target group. Use it when another team owns the load balancer.

72. What is an Ingress class?

The name that selects which controller handles the Ingress. Two controllers without classes will both try, or neither will.

73. What is a certificate on an ALB?

An ACM certificate ARN on the Ingress annotation. The name on the certificate must match the host. Kubernetes TLS secrets are a different path.

74. What is external-dns?

A controller that writes Route 53 records from Ingress or Service hosts. Give it a narrow IAM policy on one zone, or it can rewrite DNS you did not mean.

75. What is a health check failure on the ALB?

The target's probe path returns non-200, or the security group blocks the node port. Pods can be Ready in Kubernetes and unhealthy in the target group.

76. What is a readiness gate?

An extra condition the load balancer controller adds so a pod is not Ready until the target group says healthy. It stops a deploy from cutting over too early.

77. How do you upgrade add-ons with the cluster?

Move the control plane, then the add-on versions AWS marks compatible, then the node groups. An old CNI on a new control plane is a known source of odd networking bugs.

78. What is a force update of a node group?

It replaces nodes even when a PDB or a pod error would have stopped the roll. Use it only when you accept the eviction. It can take down a single replica.

79. What is a PodDisruptionBudget of minAvailable equal to replicas?

Zero pods may leave. The node-group update stalls. Lower the minimum for the window, or add a replica first.

80. How do you see why a node group update stalled?

Describe the update in EKS and describe the pods on the node being drained. The event names the PDB or the volume that will not detach.

81. What is a stuck EBS volume?

The disk is still attached to a stopping instance. The new pod stays in ContainerCreating. Force-detach only when you know the old node is gone.

82. What is a multi-AZ node group?

Instances spread across the subnets you listed. A zone outage loses only that share. Pin a stateful volume to a zone or it may not reattach.

83. What is topology spread?

A pod rule that keeps replicas in different zones or nodes. It needs the nodes to already exist in those zones.

84. What is a cluster's Kubernetes support calendar?

Each minor has a standard support end. Track it. Extended support is the expensive fallback, not the plan.

85. What is eksctl?

A CLI that creates clusters from a YAML file. Fine for a lab. A shared environment should use Terraform or CloudFormation so the change is reviewed.

86. What belongs in Terraform versus Helm?

The cluster, node groups, IAM, and add-ons belong in the infrastructure code. Deployments and Services belong in Helm or Kustomize. One state file for both becomes unreadable.

87. What is a data source for a cluster?

A read of a cluster that already exists. Use it when the workload stack is separate from the cluster stack, so a workload plan cannot destroy the cluster.

88. How do you avoid a plan that replaces the cluster?

Read the plan. A change to the VPC, the endpoint mode, or the name often forces a new cluster. Do not apply that on a Friday.

89. What is a blue-green cluster?

A second cluster on the new version, traffic shifted at DNS or the load balancer, then the old cluster removed. It costs double for a while and avoids an in-place leap.

90. What is a canary node group?

A small group on the new AMI or minor. Schedule a slice of traffic there. Roll the rest only after it stays healthy.

91. What is CloudTrail for EKS?

The API audit of who called UpdateClusterVersion or changed a role. Kubernetes audit logs are separate and live in CloudWatch if you enabled them.

92. What is GuardDuty for EKS?

A detector for suspicious API calls and, with the agent, runtime findings. It does not replace image scanning or network policy.

93. What is image scanning?

ECR can scan for known vulnerabilities on push. A critical finding should block the deploy in the pipeline, not wait for a human to open the console.

94. What is a signed image?

An image with a provenance signature. A policy can reject unsigned images at admission. Signing happens in CI, verification in the cluster.

95. What is admission control?

Webhooks that accept or reject objects. Use them for policy. Do not depend on people remembering the rules.

96. What is a service quota?

The account limit on vCPUs, load balancers, or elastic IPs. A node-group scale fails at the quota even when the Kubernetes objects are correct.

97. How do you test an upgrade before production?

A cluster with the same version, add-ons, and a copy of the stateful workload. Run the same minor step there. A kind cluster does not test the AWS add-ons.

98. What is the first command when nodes are NotReady?

Describe the node. Then check aws-node and kube-proxy. Then the instance status in EC2. The Kubernetes view and the EC2 view can disagree.

99. What is a common private-cluster pull failure?

No ECR or S3 endpoint and no NAT. The node cannot download layers. Add the endpoints or a NAT path.

100. What should a runbook list before UpdateClusterVersion?

Current minor, target minor, add-on compatibility, PDB exceptions, quota, and the node-group update that follows. The control plane alone is not the whole upgrade.
