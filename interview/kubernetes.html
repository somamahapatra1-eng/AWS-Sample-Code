Kubernetes: 100 interview questions

Thirty-four beginner questions, thirty-three intermediate, and thirty-three advanced. Each one has a direct answer.

Beginner

1. What is Kubernetes?

A control plane that keeps a declared set of containers running on a group of machines. You say what you want. Controllers try to make the cluster match.

2. What is a cluster?

The control plane plus the worker nodes. One cluster can hold many namespaces and teams.

3. What is the API server?

The front door. kubectl and controllers talk to it. It stores objects in etcd.

4. What is etcd?

The key-value store of the cluster's objects. Lose it without a backup and the cluster's memory is gone. Managed services run it for you.

5. What is the scheduler?

It picks a node for each pod that has no node yet. It looks at requests, taints, and affinity.

6. What is a controller?

A loop that watches objects and changes the cluster until reality matches them. Deployments, jobs, and cloud controllers are all controllers.

7. What is a pod?

The smallest unit you run. One or more containers share a network namespace and volumes. They are scheduled together.

8. What is a container in a pod?

A process with its own image. Sidecars are extra containers in the same pod, such as a proxy or a log shipper.

9. What is a ReplicaSet?

It keeps a number of pod copies running. You usually do not create one yourself. A Deployment creates it.

10. What is a Deployment?

It manages ReplicaSets so you can roll out a new image and roll back. It is the default for a stateless app.

11. What is a rolling update?

New pods come up before old pods are removed, within the surge and unavailable limits. A bad readiness probe makes the roll stall.

12. What is a rollback?

The Deployment goes back to the previous ReplicaSet. It does not undo a database migration. Plan those separately.

13. What is a StatefulSet?

Pods with stable names and stable disks, started and updated in order. Use it for systems that need identity, such as a database.

14. What is a DaemonSet?

One pod per selected node. Log agents and network plugins use it. A node that cannot run it may be NotReady.

15. What is a Job?

A pod that should run to completion. Kubernetes restarts it until it succeeds or hits the backoff limit.

16. What is a CronJob?

A Job on a schedule. Set a concurrency policy so a slow run does not stack on the next tick.

17. What is a Service?

A stable virtual IP and DNS name in front of pods selected by labels. The pods can come and go.

18. What is ClusterIP?

A Service reachable only inside the cluster. It is the default and the right choice for most internal calls.

19. What is NodePort?

A port on every node that forwards to the Service. Useful for a lab. A cloud load balancer is the usual production path.

20. What is a headless Service?

A Service with no cluster IP. DNS returns the pod addresses. StatefulSets use it so clients can find pod 0 and pod 1.

21. What is an endpoint?

The pod addresses behind a Service. If the selector matches nothing, the Service has no endpoints and calls fail.

22. What is kube-proxy?

The node component that programs rules so ClusterIP traffic reaches a pod. If it is down, Service IPs fail and pod IPs may still work.

23. What is CoreDNS?

The cluster DNS. It answers names like payment.billing.svc.cluster.local. If it is down, names fail and IPs still work.

24. What is an Ingress?

An HTTP rule: this host and path go to that Service. A controller turns the object into a real proxy or load balancer.

25. What is an Ingress class?

Which controller should handle the Ingress. Without it, the wrong controller, or no controller, takes the object.

26. What is the Gateway API?

A newer set of objects for traffic, with roles for infrastructure and for app teams. It is the direction after Ingress.

27. What is a ConfigMap?

Configuration files or keys mounted into a pod. Changing it does not restart the pod unless something else does.

28. What is a Secret?

Small sensitive data. It is stored in etcd. Restrict who can read it, and turn on encryption if the platform offers it.

29. What is a volume?

A directory visible to containers in the pod. It can be a disk, a secret, or an empty directory.

30. What is a PersistentVolume?

A piece of storage in the cluster. Admins can create it, or a storage class can create it on demand.

31. What is a PersistentVolumeClaim?

A request for storage. The pod mounts the claim. The claim binds to a volume that matches size and mode.

32. What is a StorageClass?

The provisioner and parameters for new volumes, such as SSD or a shared file system. A default class is used when the claim names none.

33. What is ReadWriteOnce?

The volume mounts on one node. A second pod on another node waits. Shared files need ReadWriteMany.

34. What is a namespace?

A boundary for names and, if you add them, quotas and policy. It is not a strong security boundary by itself.

Intermediate

35. What is a label?

A key the selector matches. Services, deployments, and network policy all select by labels. A typo means an empty Service.

36. What is an annotation?

Metadata that tools read, such as a load balancer class. The scheduler does not select on annotations.

37. What is a resource request?

What the scheduler reserves. A pod with no requests can land on a full node and starve neighbors.

38. What is a resource limit?

The cap. Memory over the limit kills the container. CPU over the limit throttles it.

39. What is QoS?

Guaranteed, Burstable, or BestEffort, based on requests and limits. Under pressure, BestEffort is killed first.

40. What is a limit range?

Defaults and maximums for containers in a namespace. It fills in requests when the author forgot them.

41. What is a resource quota?

A cap on the namespace: total CPU, memory, or number of pods. The API rejects creates that would exceed it.

42. What is a probe?

A check the kubelet runs: startup, readiness, or liveness. They are HTTP, TCP, or a command.

43. What is a readiness probe?

When it fails, the pod leaves the Service. The container is not restarted. Use it so traffic waits until the app can serve.

44. What is a liveness probe?

When it fails, the container restarts. A probe that fails during a long start will crash-loop the app. Use a startup probe.

45. What is a startup probe?

It holds liveness back until the app has started. Slow Java processes need this so they are not killed while warming up.

46. What is a PodDisruptionBudget?

How many pods must stay up during a voluntary drain. It does not protect against a node crash.

47. What is a voluntary disruption?

A drain, a scale-down, or an upgrade. The budget applies. A kernel panic is involuntary and ignores the budget.

48. What is kubectl drain?

Cordon the node, then evict pods so they start elsewhere. A budget that allows no evictions makes drain wait.

49. What is cordon?

The node takes no new pods. Existing pods keep running.

50. What is a taint?

A mark on a node that repels pods. A pod must tolerate the taint to land there. Use it for GPU nodes or a system pool.

51. What is a toleration?

The pod's permission to ignore a taint. It does not attract the pod. A node selector or affinity does that.

52. What is node affinity?

A preference or a rule for which nodes a pod may use, matched on labels.

53. What is pod anti-affinity?

A rule that keeps replicas off the same node or zone. It raises availability and can leave pods pending if the cluster is small.

54. What is a topology spread constraint?

A rule that balances pods across zones or nodes. The scheduler will not pile them into one zone if the constraint is hard.

55. What is a priority class?

A rank. When the node is full, a higher priority pod can preempt a lower one. Use it sparingly.

56. What is preemption?

A lower priority pod is evicted to make room. It is disruptive. Do not set every app to the highest class.

57. What is HPA?

The horizontal pod autoscaler. It changes replica count from CPU, memory, or a custom metric. CPU needs a request or the math has no baseline.

58. What is VPA?

The vertical pod autoscaler. It recommends or sets requests. Changing requests restarts the pod. It does not add nodes.

59. What is the cluster autoscaler?

It adds or removes nodes when pods are pending or nodes are idle. It is a different loop from HPA.

60. What is metrics-server?

The source for kubectl top and for CPU-based HPA. If it is missing, both fail.

61. What is a ServiceAccount?

The identity of a pod. The API server mounts a token. Bind roles to the account, not to every user, for workload access.

62. What is RBAC?

Roles and bindings. A Role is namespaced. A ClusterRole is cluster-wide. A binding grants it to a user or a service account.

63. What is a RoleBinding?

It grants a role inside one namespace. Prefer it over a ClusterRoleBinding for an app.

64. What is a ClusterRoleBinding?

It grants a cluster role everywhere. cluster-admin this way is how a small token becomes a full compromise.

65. What is the default service account?

The one pods get if you name none. Do not bind rights to it. Set automountServiceAccountToken to false when the pod does not call the API.

66. What is a NetworkPolicy?

A rule for which pods may connect. It does nothing until the cluster's network plugin enforces it. A default deny plus allows is the usual pattern.

67. What is ingress versus egress policy?

Ingress is who may connect to the pod. Egress is where the pod may connect. Forgetting egress breaks DNS if you deny all egress and forget UDP 53.

Advanced

68. What is Kustomize?

A way to patch manifests without a templating language. Bases and overlays keep dev and prod close.

69. What is Helm?

Charts, templates, and releases. A release is one install. Upgrade changes it. Rollback returns to an older release.

70. What is a Helm values file?

The inputs to the templates. Secrets in a values file in Git are still secrets in Git. Use an external secret or a sealed value.

71. What is an operator?

A controller with custom resources that knows how to run a complex system, such as a database. It is extra software you must upgrade and trust.

72. What is a CRD?

A custom resource definition. It adds a new kind to the API. The controller that acts on it is separate. A CRD alone does nothing.

73. What is an admission webhook?

An HTTP call the API server makes before it saves an object. Policy and mutation use it. A down webhook can block all deploys if it is set to fail closed.

74. What is failure policy Fail versus Ignore?

Fail rejects the object when the webhook is down. Ignore allows it. Fail is safer and can lock the cluster if the webhook pods are broken.

75. What is a ValidatingAdmissionPolicy?

A policy written in the API, without a webhook process, for rules the language can express. Use it when you do not want another deployment.

76. What is a PodMonitor or ServiceMonitor?

A Prometheus operator object that says where to scrape. The pods still need to expose metrics.

77. What is a liveness probe that checks a dependency?

A bad probe. If the database blips, every app pod restarts and the database gets a stampede. Readiness can fail. Liveness should mean the process is stuck.

78. What is a crash loop?

The container exits, restarts, and the delay grows. Read logs --previous. The current logs may be empty if it dies immediately.

79. What is ImagePullBackOff?

The runtime cannot pull the image. Wrong name, missing tag, or no credentials. The events have the registry's error.

80. What is CreateContainerConfigError?

A secret or config map named in the pod does not exist, or a key is missing. The pod never starts.

81. What is Pending?

The scheduler has not bound a node, or a volume is not bound. Describe the pod. The events say which constraint failed.

82. What is OOMKilled?

The container crossed its memory limit or the node ran out. Look at the limit before you blame the code, and at the code before you raise the limit forever.

83. What is eviction?

The kubelet kills pods when the node is low on disk, memory, or inodes. Requests decide who is at risk. A limit does not protect a pod from node pressure the way people hope.

84. What is a PodCondition?

Ready, Initialized, ContainersReady, and PodScheduled. A pod can be Running and not Ready. Traffic uses Ready.

85. What is a Deployment maxUnavailable of 0?

The roll adds new pods before it removes old ones. You need spare capacity. Combined with a tight PDB it can stall.

86. What is a canary?

A small replica count on the new version. You watch errors, then raise it. A Deployment alone is a rolling update, not a canary, unless you split Services.

87. What is a blue-green deploy?

Two full sets, and you switch the Service. It costs double and the rollback is a switch back. Migrations still only go one way.

88. What is GitOps?

A controller applies Git. Drift gets corrected. The pull request is the review. Someone must still own the controller's rights.

89. What is a reconciliation fight?

GitOps sets replicas to 3 and HPA sets them to 8. Ignore the replica field in Git or turn one of them off.

90. What is a namespace per team?

A reasonable default. Add a quota, a network policy, and a role binding. The namespace name is not the security control. Those objects are.

91. What is a cluster per environment?

Stronger isolation than a namespace. More control planes to upgrade. Use it when blast radius matters more than cost.

92. How do you upgrade Kubernetes?

One minor at a time. Control plane first on managed services, then nodes. Check PDBs and API removals in the changelog before you start.

93. What is a deprecated API?

A version that will disappear, such as an old Ingress version. Convert manifests before the upgrade that removes them, or the apply fails after.

94. What is kubectl convert or a plugin?

A way to rewrite manifests to a newer API version. Test the result. Do not convert in production as the first try.

95. What is a skew policy?

How far nodes may lag the control plane. The project documents it. Managed clouds add their own window. Do not invent a skip.

96. What is etcd backup on a self-managed cluster?

A snapshot you have restored at least once. A snapshot you have never restored is a hope. Managed control planes shift this duty to the provider.

97. What is a static pod?

A pod the kubelet starts from a file on the node, not from the API. Control-plane components on a self-managed cluster are often static pods.

98. What is a control plane on workers?

A bad mix unless you mean a small lab. Taints keep workloads off control-plane nodes so a busy app cannot starve etcd.

99. What is a certificate rotation?

API server certificates expire. Managed services rotate them. A self-managed cluster needs a process, or kubectl fails on a date nobody remembers.

100. What should an on-call person check first?

Recent deploys, failing pods, node conditions, and the error rate. A dashboard that only shows CPU will miss a bad release.
