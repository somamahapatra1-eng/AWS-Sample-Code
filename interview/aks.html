AKS: 100 interview questions

Thirty-four beginner questions, thirty-three intermediate, and thirty-three advanced. Each one has a direct answer.

Beginner

1. What is AKS?

Azure Kubernetes Service is Azure's managed Kubernetes. Microsoft runs the control plane. You run workloads on node pools that you size and upgrade.

2. What does Microsoft manage in AKS?

The API server, etcd, scheduler, and controller manager. You still own node pools, Kubernetes objects, identities, networking choices, and the applications.

3. What is a node pool?

A set of virtual machines that share a size, an OS, and a Kubernetes version. Pods are scheduled onto those nodes.

4. What is the difference between a system node pool and a user node pool?

The system pool runs cluster components such as CoreDNS and metrics. User pools run your applications. Keep at least one system pool.

5. How do you point kubectl at a new cluster?

Run az aks get-credentials. It writes a context into your kubeconfig using the cluster's API server address.

6. What is the node resource group?

AKS creates a second resource group, often named MC_*, for the virtual machines, load balancers, and disks it manages. Do not rename or delete those resources by hand.

7. What is Azure CNI?

A network plugin that gives pods IP addresses from the virtual network subnet. Those pods can be reached by other Azure resources without NAT.

8. What is kubenet?

An older plugin that uses a private pod network and NAT. It uses fewer subnet IPs. New clusters usually prefer Azure CNI.

9. Why do Azure CNI clusters run out of IPs?

Each pod takes a subnet address. The subnet must be large enough for nodes plus the maximum pods per node.

10. What is a Kubernetes version in AKS?

The minor version of the control plane, such as 1.35. Node pools have their own orchestrator version and are upgraded after the control plane.

11. Can you skip minor versions when upgrading AKS?

No. Move one minor at a time: 1.33, then 1.34, then 1.35. az aks get-upgrades shows the versions Azure will accept.

12. Who pays for an AKS cluster?

You pay for the node-pool virtual machines, disks, load balancers, and outbound data. The control plane has a free tier and a paid tier with an uptime SLA.

13. What does az aks stop do?

It stops the node pools so compute charges drop. The control-plane definition remains. Start brings the same pools back. Disks are still billed while stopped.

14. What is a deployment?

A controller that keeps a set of identical pods running. You change the image or replica count on the deployment, and it rolls the pods.

15. What is a Service?

A stable address and port in front of a set of pods. ClusterIP is inside the cluster. LoadBalancer asks Azure for a public or internal load balancer.

16. What is an Ingress?

An HTTP router. A controller, such as a managed NGINX or Application Gateway, reads Ingress objects and sends host and path traffic to Services.

17. How does a cluster pull from Azure Container Registry?

Attach the registry with a managed identity, or grant that identity AcrPull. Nodes then pull images without a stored password.

18. What is a managed identity on AKS?

An Azure AD identity the cluster or a workload uses to call Azure APIs. Prefer it over a service principal secret stored in the cluster.

19. What is Kubernetes RBAC?

Roles and RoleBindings that decide what a user or service account can do inside the cluster. It is separate from Azure RBAC on the Azure resource.

20. What is Azure RBAC for Kubernetes?

An option that stores Kubernetes authorization in Azure AD. Access is granted with Azure role assignments instead of only cluster RoleBindings.

21. What is a namespace?

A folder inside one cluster. Use it to separate teams or environments. Names of Services and deployments only have to be unique inside the namespace.

22. What is a ConfigMap?

Plain configuration data, such as a file or environment values, mounted into a pod. It is not a secret store.

23. What is a Secret?

Small sensitive data held in etcd. Treat it as encoded, not encrypted, unless you turn on encryption at the application or etcd layer and lock down access.

24. What is a readiness probe?

A check that tells the Service when a pod can receive traffic. A failing readiness probe removes the pod from the endpoints. It does not restart the pod.

25. What is a liveness probe?

A check that restarts the container when the process is stuck. Use it for deadlocks, not for slow startup. Startup probes cover slow starts.

26. What is Helm?

A package tool for Kubernetes. A chart is a set of templates. A release is one install of that chart into a namespace.

27. What is kubectl describe good for?

It shows events, conditions, and the reason a pod is pending or a node is not ready. Start there before reading every log.

28. What does CrashLoopBackOff mean?

The container starts, exits, and Kubernetes waits longer between restarts. Read the previous container logs with kubectl logs --previous.

29. What is a resource request?

The CPU and memory Kubernetes reserves for scheduling. The pod is placed only on a node that still has that much free.

30. What is a resource limit?

The maximum the container may use. Hitting the memory limit kills the container. Hitting the CPU limit throttles it.

31. What is a PodDisruptionBudget?

A rule for voluntary disruptions such as a drain. minAvailable or maxUnavailable says how many pods must stay up. A budget of zero evictions blocks a node upgrade.

32. How do you scale a node pool?

Change the minimum, maximum, or current count with az aks nodepool scale, or turn on the cluster autoscaler so pending pods add nodes.

33. What is the cluster autoscaler?

It adds nodes when pods are pending for lack of CPU or memory, and removes nodes that stay underused. It does not scale pods. The horizontal pod autoscaler does that.

34. What is a taint on a system pool?

AKS taints system pools so application pods stay off them unless they tolerate the taint. That reserves the pool for cluster components.

Intermediate

35. What is workload identity?

A way for a pod to exchange its Kubernetes service-account token for an Azure AD token. The pod then calls Azure as a specific managed identity.

36. What is a federated credential?

The Azure AD object that trusts one Kubernetes service account in one namespace. The issuer is the cluster's OIDC URL.

37. Why create the identity before the cluster?

The cluster and its workloads look the identity up. Creating it in an earlier step means the cluster plan does not depend on a name that does not exist yet.

38. What is a private AKS cluster?

The API server has a private IP only. kubectl works from a network that can route to that IP, usually through a virtual network, a VPN, or a bastion.

39. What is API server VNet integration?

The API server is projected into a delegated subnet. You choose the network path instead of a public endpoint.

40. What is an authorized IP range?

A public cluster can still limit which source IPs may reach the API server. Office and pipeline addresses belong there.

41. What is a user-assigned kubelet identity?

The identity the node uses to pull images and attach disks. AKS can create one, or you can bring one and grant it the roles it needs.

42. What goes wrong if the kubelet identity cannot pull images?

Nodes join, but pods stay in ImagePullBackOff. The identity needs AcrPull on the registry, and the cluster must actually use that identity.

43. What is a storage class?

A named way to create disks or files. A PersistentVolumeClaim asks for a size and a class. AKS provides classes such as managed and managed-csi.

44. What is the CSI driver on AKS?

The Container Storage Interface plugin that creates Azure disks or Azure Files when a claim is bound. In-tree disk plugins are retired.

45. What is zone redundancy for a node pool?

The pool spreads nodes across availability zones. A zone failure then takes only part of the pool. Pod topology spread should match that.

46. What is a max surge on a node upgrade?

How many extra nodes AKS may add while it cordons and drains the old ones. Surge shortens the upgrade and needs quota for the extra virtual machines.

47. Why does a node upgrade stop on a PDB?

Drain is voluntary. If replicas minus minAvailable is zero, no pod can be evicted. Raise replicas or lower the budget, then resume.

48. What is a spot node pool?

Virtual machines that Azure can reclaim. They are cheaper and unsuitable for the system pool or for pods that cannot be interrupted.

49. How do you keep a workload off spot nodes?

Taint the spot pool and do not tolerate that taint, or use a node selector for a regular pool.

50. What is Azure Policy for AKS?

Gatekeeper-style rules delivered as Azure Policy. A policy can reject privileged pods or require labels before the API server stores the object.

51. What is Microsoft Defender for Containers?

A security product that scans images and watches cluster runtime. It is an add-on, not a replacement for RBAC or network policy.

52. What is a network policy?

A rule for which pods may talk to which pods or addresses. AKS supports Azure Network Policy and Calico. The plugin is chosen when the cluster is created.

53. What is an internal load balancer?

A Service of type LoadBalancer annotated so Azure puts the frontend on a private IP. Only the virtual network, or peered networks, can reach it.

54. What is a static public IP on a Service?

You create the public IP first and put its resource ID on the Service. Recreating the Service then keeps the same address.

55. What is the outbound type?

How nodes reach the internet: a load balancer, a NAT gateway, or a user-defined route. The choice changes SNAT ports and who owns the firewall path.

56. What is a NAT gateway used for on AKS?

Stable outbound IPs and a larger SNAT port pool. Use it when many nodes open many outbound connections and the default load balancer SNAT is exhausted.

57. What does SNAT port exhaustion look like?

Intermittent timeouts to external APIs while pods and nodes look healthy. The load balancer metrics show failed outbound flows.

58. What is a maintenance window?

A schedule that limits when Azure may apply planned node-image upgrades. It does not replace the Kubernetes version upgrade you run yourself.

59. What is a node image upgrade?

A new virtual-machine image with OS patches, without changing the Kubernetes minor version. AKS can do this on a cadence or when you ask.

60. How is a node image upgrade different from a Kubernetes upgrade?

The node image is the OS. The orchestrator version is the kubelet. You can patch the OS and stay on the same Kubernetes minor.

61. What is Kubernetes support policy on AKS?

Azure supports a recent set of minors, about the latest and the two before it. Older minors leave support and must be upgraded.

62. What happens when a version leaves support?

Azure eventually upgrades the control plane for you, or blocks some operations until you move. Track the calendar rather than waiting for a forced upgrade.

63. How do you see which upgrades are allowed?

az aks get-upgrades returns the control-plane versions you can move to from the current one. It will not offer a skip.

64. What is a failed provisioning state?

The cluster or pool is not Succeeded. Read the activity log and az aks show. Do not start a second upgrade on top of a failed one until the first is resolved or rolled back.

65. What is kubectl drain?

It cordons a node and evicts pods so they start elsewhere. AKS does this during a node-pool upgrade. A closed PDB stops it.

66. What is cordon?

The node is marked unschedulable. Existing pods keep running. New pods go elsewhere. Drain cordons and then evicts.

67. How do you add a second node pool without downtime?

Create the pool, confirm nodes are Ready, move workloads with selectors or a larger replica count, then scale the old pool down.

Advanced

68. How do you rotate a registry credential?

Prefer a managed identity so there is no password. If you must use a token, store it in a secret source, mount it, and roll the pods.

69. What is image pull policy IfNotPresent?

The node reuses a local image if the tag is already there. A moving tag such as latest can hide a new build. Pin a digest or a unique tag.

70. Why avoid the latest tag?

You cannot tell which build is running, and a node that already pulled latest will not pull again. Use an immutable tag or a digest.

71. What is a pod security admission label?

A namespace label that enforces privileged, baseline, or restricted policy. Restricted blocks host access, privileged containers, and many unsafe settings.

72. What is a hostPath volume risk?

The container sees the node's filesystem. A write can damage the node. Disallow it except for trusted system DaemonSets.

73. What is privileged: true?

The container is nearly root on the node. Application pods should not set it. Only a few infrastructure DaemonSets need it.

74. How do you debug a pending pod?

kubectl describe shows the scheduler message: insufficient CPU, untolerated taint, unbound volume, or a node selector that matches nothing.

75. What is an unbound PersistentVolumeClaim?

No volume matches the size, class, or mode. The pod stays pending. Check the storage class name and the zone of the disk versus the node.

76. Why do Azure disks fail to attach across zones?

A managed disk lives in one zone. A pod that moves to another zone cannot attach it. Use a zone-pinned pool or a storage class that matches.

77. What is Azure Files good for?

A share that several pods can mount, such as ReadWriteMany. Disks are usually ReadWriteOnce, one node at a time.

78. What is a private DNS zone for the API server?

The name of the private API server resolves only inside a linked virtual network. The cluster module looks the zone up. The zone must already exist.

79. What breaks if the private DNS zone link is missing?

Names do not resolve, or they resolve to the wrong address. kubectl times out even when the API server is healthy.

80. What is CoreDNS?

The cluster DNS service. Pods resolve Service names through it. If CoreDNS is down, Services fail while pod IPs still work.

81. How do you see CoreDNS problems?

Look at the CoreDNS pods in kube-system and the Service named kube-dns. A bad upstream or a network policy that blocks UDP 53 is a common cause.

82. What is a horizontal pod autoscaler?

It changes the replica count from CPU, memory, or a custom metric. It needs requests set, or CPU utilization has no baseline.

83. What is metrics-server?

The cluster component that serves CPU and memory numbers to kubectl top and to the horizontal pod autoscaler. Without it, those commands fail.

84. What is Container Insights?

An Azure Monitor add-on that collects logs and metrics from the cluster. It is optional and has its own data charge.

85. How is Container Insights different from kubectl logs?

kubectl logs reads the current container stream. Container Insights keeps logs after the pod is gone and lets you query them.

86. What is a diagnostic setting?

A rule that sends Azure resource logs, such as the API server audit, to a Log Analytics workspace or storage account.

87. What should an upgrade runbook check first?

The current version, the next allowed minor, quota for surge nodes, and every PodDisruptionBudget that allows zero evictions.

88. How do you resume a node-pool upgrade that stopped?

Fix the PDB or the failing pod, then run the node-pool upgrade again for the same target version. Do not jump to a newer minor.

89. What is a blue-green node pool upgrade?

Add a pool on the new version, shift traffic, then delete the old pool. It costs more during the overlap and avoids an in-place drain of the only pool.

90. What is cluster autoscaler expander?

The strategy for which pool grows when several could. Priority or least-waste stops the autoscaler from always growing the most expensive pool.

91. How do you give a pipeline just enough access?

A dedicated identity with Azure Kubernetes Service Cluster User Role, plus a Kubernetes role in the namespaces it deploys. Not Owner on the subscription.

92. What is local account disabled?

The cluster rejects certificates that are not Azure AD. Every kubectl caller must be an Azure AD user or identity. Break-glass access must be planned.

93. What is a run command?

az aks command invoke runs a command on the cluster from Azure without a local kubeconfig. Useful for a private cluster from a pipeline.

94. What is infrastructure as code for AKS?

The cluster, pools, identities, and DNS live in Terraform, Bicep, or OpenTofu. kubectl applies only workload manifests. Mixing both into one unreviewed script drifts.

95. Why split identity and DNS from the cluster module?

The cluster looks them up. Creating them first gives each piece its own state and a failed cluster apply cannot delete the identity as a side effect.

96. What is terraform state for a node pool?

The pool's size, version, and labels. Changing them in the portal and not in code makes the next plan fight the portal. Pick one writer.

97. What is a reconciliation loop?

A controller keeps changing an object back to what it wants. An autoscaler and a GitOps tool can fight if both set the same replica count.

98. How do you confirm a cluster upgrade finished?

The control plane provisioning state is Succeeded and kubernetesVersion matches. Each pool's orchestrator version matches the version you intended. Nodes are Ready.

99. What is a partial upgrade?

The control plane moved and a node pool did not. Workloads still run, but you are mid-upgrade. Finish or roll the pool before starting another minor.

100. What should you never put in a public repository?

Kubeconfigs, registry passwords, storage account keys, and subscription identifiers tied to a real environment. Use identity and a secret store.
