CloudFormation: Infrastructure as Code

What It Does

CloudFormation is AWS's declarative infrastructure language. You write YAML or JSON templates that describe your infrastructure, and CloudFormation creates, updates, and deletes the resources as one unit. No more clicking the console.

A stack is one deployment. A nested stack is a stack that creates other stacks, letting you build reusable components.

Core Features

  • Mappings — Lookup tables. Map region → availability zones, or env → instance size.
  • Parameters — User inputs. TenantId, Environment, etc.
  • Conditions — If/then logic. if prod then retain data else delete.
  • Fn::Sub — String interpolation. ${Variable} inside values.
  • Fn::GetAtt — Get outputs from a resource. The queue URL, the role ARN.
  • Fn::FindInMap — Lookup a mapping. FindInMap [RegionConfig, us-east-1, QueueSuffix].

Simple Example

AWSTemplateFormatVersion: "2010-09-09"

Parameters:
  TenantId:
    Type: String
    Default: acme

Mappings:
  RegionConfig:
    us-east-1:
      QueueName: acme-queue-use1
    eu-west-1:
      QueueName: acme-queue-euw1

Resources:
  Queue:
    Type: AWS::SQS::Queue
    Properties:
      QueueName: !FindInMap [RegionConfig, !Ref "AWS::Region", QueueName]

Outputs:
  QueueUrl:
    Value: !Ref Queue
  QueueArn:
    Value: !GetAtt Queue.Arn
Key intrinsic functions:
!Ref Parameter — The parameter value.
!GetAtt Resource.Property — An output from the resource.
!Sub "${VarName}" — String with variables replaced.
!FindInMap [Map, TopKey, SecondKey] — Lookup from a mapping.

Nested Stacks

Call another template as a resource. The root stack passes parameters to the nested stack and receives outputs. 

  TenantStack:
    Type: AWS::CloudFormation::Stack
    Properties:
      TemplateURL: https://example.com/tenant.yaml
      Parameters:
        TenantId: !Ref TenantId
        QueueArn: !GetAtt Shared.Outputs.QueueArn

  Outputs:
    TenantQueueUrl:
      Value: !GetAtt TenantStack.Outputs.QueueUrl

Conditions for Multi-Environment

Conditions:
  IsProduction: !Equals [!Ref Environment, prod]

Resources:
  Bucket:
    Type: AWS::S3::Bucket
    DeletionPolicy: !If [IsProduction, Retain, Delete]

  BucketPolicy:
    Type: AWS::S3::BucketPolicy
    Condition: !If [IsProduction, true, false]
    Properties:
      ...

When to Use

CloudFormation is best for:

  • Multi-tenant stacks where each tenant gets similar resources (role, queue, bucket prefix)
  • Repeatable deployments across regions
  • Infrastructure that must be version-controlled and reviewable
  • DevOps pipelines where infrastructure changes are tracked

Key Gotchas

  • TemplateURL must be HTTPS — Publish templates to S3 with a public or signed URL.
  • Stack names are immutable — You cannot rename a stack; you must create a new one.
  • Circular dependencies — If a nested stack outputs something the parent needs for a parameter, use Fn::GetAtt on the nested stack instead.
  • DeletionPolicy — By default, CloudFormation deletes S3 buckets and RDS instances. Use Retain for production data.
