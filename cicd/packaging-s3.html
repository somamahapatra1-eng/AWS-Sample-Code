Packaging Code and Uploading to S3

Why Package?

Lambda, CodeBuild, and CodePipeline cannot clone a Git repo and run code directly. You must package your code into a ZIP file and upload it to S3. CloudFormation then pulls that ZIP, extracts it, and deploys it.

What Gets Zipped

For a Lambda, the ZIP must have the handler function at the root: 

router.zip
├── router.py         ← handler module at the root
├── lib/
│   └── helper.py
└── config.json

If the handler is not at the root, Lambda cannot find it. The ZIP structure matters.

PowerShell Packaging

$root = Split-Path -Parent $PSScriptRoot
$destDir = Join-Path $root "dist"
$dest = Join-Path $destDir "router.zip"
New-Item -ItemType Directory -Force -Path $destDir | Out-Null
if (Test-Path $dest) { Remove-Item $dest }
Compress-Archive -Path (Join-Path $root "src\router.py") -DestinationPath $dest
Write-Output $dest
With dependencies: Include the full directory:
Compress-Archive -Path (Join-Path $root "src\*") -DestinationPath $dest

Upload to S3

Store the ZIP in an S3 bucket that CloudFormation can read. 

aws s3 cp dist/router.zip s3://my-artifacts-bucket/router.zip
aws s3 cp dist/router.zip s3://my-artifacts-bucket/router-$(git rev-parse --short HEAD).zip

CloudFormation Lambda Code Reference

Resources:
  Router:
    Type: AWS::Lambda::Function
    Properties:
      FunctionName: my-router
      Runtime: python3.12
      Handler: router.handler
      Role: !GetAtt RouterRole.Arn
      Code:
        S3Bucket: my-artifacts-bucket
        S3Key: router.zip
S3 bucket must be in the same region as the Lambda. CodePipeline handles cross-region copies automatically.

CodePipeline with Artifacts

CodePipeline stages pass artifacts to each other through S3. A Source stage outputs a ZIP of your repo. A Build stage (CodeBuild) runs and outputs a new artifact (the packaged code). A Deploy stage takes that artifact and feeds it to CloudFormation. 

Stages:
  - Name: Source
    Actions:
      - Name: SourceZip
        ActionTypeId:
          Provider: S3
        Configuration:
          S3Bucket: my-source-bucket
          S3ObjectKey: source.zip
        OutputArtifacts:
          - Name: SourceOutput

  - Name: Build
    Actions:
      - Name: Package
        ActionTypeId:
          Provider: CodeBuild
        InputArtifacts:
          - Name: SourceOutput
        OutputArtifacts:
          - Name: BuildOutput

  - Name: Deploy
    Actions:
      - Name: CreateChangeSet
        ActionTypeId:
          Provider: CloudFormation
        InputArtifacts:
          - Name: BuildOutput
        Configuration:
          TemplatePath: BuildOutput::templates/main.yaml

CodeBuild buildspec.yml

The build job unzips the source, runs tests, packages the code, and uploads the result. 

version: 0.2

phases:
  install:
    runtime-versions:
      python: 3.12

  pre_build:
    commands:
      - python -m unittest discover -s tests -v

  build:
    commands:
      - mkdir -p dist
      - cd src && zip -r ../dist/router.zip router.py && cd ..
      - aws s3 cp dist/router.zip s3://$ARTIFACT_BUCKET/router.zip

  post_build:
    commands:
      - echo "Package complete"

artifacts:
  files:
    - templates/**/*
    - dist/router.zip
  discard-paths: yes
